# BudgetSplit

Set your income, split it your way, and track every expense — all in one place.

A lightweight budget tool based on the 50/30/20 rule. Adjust spending ratios with sliders, log expenses under each category, and export/import your data as CSV.

## Live Demo
https://volibeartea.github.io/BudgetSplit

## Features
- Set monthly income
- Customize Needs / Wants / Savings ratios
- Log itemized expenses with descriptions
- Export & import data as CSV
